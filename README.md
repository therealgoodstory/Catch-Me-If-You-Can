# Catch Me If You Can

An interactive world map of extradition treaties between countries, with a game on top of it.

Pick a country and see which countries it has an extradition treaty with. Or play: start in a random country and keep jumping to countries that have no treaty with the one you are in. Jump to one that does and you are caught.

**Play it:** https://therealgoodstory.github.io/Catch-Me-If-You-Can/

*The treaty data was researched with the help of an LLM and may be incomplete or out of date. Verify anything important against official sources.*
